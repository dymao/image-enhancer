# Image Enhancer

一个本地运行的桌面修图工具，主界面基于 Electron，支持图片基础增强、人像美化、海报生成、拼图排版、文字编辑、马赛克遮挡、历史回退和深浅色主题切换。所有处理在本地完成，适合日常修图、社交分享图、商品图、证件照和海报快速制作。

## 项目说明

- `electron/` 是当前推荐使用的新桌面界面，提供三栏式工作区、左侧一键预设、中心画布和右侧工具箱。
- `src/` 保留 PyQt 旧界面，可作为备用启动方式。
- 图片处理以本地 Canvas / OpenCV 能力为主，不依赖云端上传图片。
- macOS 可通过 `Image Enhancer.app` 或 `start_electron.command` 启动，Windows 可通过 `start_image_enhancer_windows.cmd` 一键启动。
- 导出时会按当前编辑状态重新生成图片，预览阶段会使用适合窗口的缩略图提升交互速度。

## 功能

- 打开 JPG、PNG、WEBP、BMP、TIFF 图片
- 调整亮度、对比度、饱和度
- 锐化图片细节
- 降噪处理
- 人像一键美化
- 婚纱照一键精修
- 风格化一键修图
- 海报一键生成，支持旅行、婚礼、商品、节日、社交分享等海报样式
- 拼图一键排版，支持双图、三图、四图、五图、六图、九宫格及主次/横竖/错落布局
- 图片文字编辑，支持字体、颜色、大小、样式预设、拖动和删除
- 马赛克遮挡，支持矩形、椭圆、像素块、模糊、纯色和图案遮罩
- 历史操作记录，支持删除单条记录和回退上一步
- 深色、白色和跟随系统主题
- 美白、磨皮、瘦脸
- 柔光通透效果
- 经典黑白效果
- 左右旋转 90 度
- 预览缩放
- 导出 PNG、JPG、WEBP、BMP

## 人像美化

- 点击“人像一键美化”会自动设置推荐参数，包括亮度、对比度、饱和度、锐化、降噪、美白、磨皮和瘦脸。
- “美白”会先识别图片中的肤色区域，再局部提升肤色亮度，避免把背景、婚纱、天空一起变白。
- “磨皮”会基于肤色软蒙版做局部平滑，尽量保留背景、衣服和整体轮廓细节。
- “瘦脸”使用 OpenCV 本地人脸检测，对检测到的人脸区域做轻微横向收窄；如果检测不到人脸，会自动跳过，不影响其他效果。

## 婚纱照一键精修

- 点击“婚纱照一键精修”会自动应用偏柔和、通透、干净的参数组合。
- 默认会增强美白、磨皮和柔光，同时轻微提升亮度、对比度和饱和度。
- 美白和磨皮会优先作用在人像肤色区域，不会直接把整张婚纱照全部磨糊。
- “柔光”适合婚纱照、写真照和外景照，可以让高光更柔和、画面更明亮。

## 风格化一键修图

- 左侧默认只显示“风格化一键修图”入口，点击后才展开具体风格样式。
- “蓝天白云”：增强蓝色天空、提亮白云和高光，适合户外旅行照、外景照。
- “青色青春”：加入清爽青绿色调，同时保护人物肤色，适合校园、人像、写真。
- “暖阳胶片”：增加暖色高光和轻胶片感，适合日落、逆光、外景氛围照。
- “高级灰”：降低整体饱和度并增强层次，适合质感大片、商务照和简约风。
- “甜美樱花”：粉色高光、柔和肤色，适合少女写真和甜美人像。
- “赛博夜景”：蓝紫霓虹、高对比，适合城市夜拍和氛围街拍。
- “森林清新”：强化自然绿意和通透感，适合草地、树林、户外照。
- “复古港风”：暖红暗部和复古对比，适合街拍、人像和怀旧照片。
- “经典黑白”：黑白层次和强对比，适合纪实、肖像和情绪大片。

## 拼图一键排版

- 点击左侧“拼图一键排版”可展开两张竖拼、两张横拼、三张横排/竖排/主次拼、四图布局、五图布局、六图布局和九宫格。
- 选择拼图样式后会优先复用当前已经打开的图片，不会重复新建 tab。
- 如果当前图片不足，拼图会保留白灰棋盘格空位；点击空位可选择图片填入，也可按空位顺序自动补图。
- 如果当前图片超过目标布局数量，会提示用户点击图片右上角红叉删除多余图片。
- 在拼图 tab 内点击格子可选中图片，拖动可调整裁切位置，滚轮可放大或缩小当前格图片。
- 已填图片可拖到空位，也可拖到其他已填格子进行交换，不会覆盖原图片。
- 选中图片后可点击右上角红叉删除，也可按 `Delete` 或 `Backspace` 删除当前选中格图片。
- 导出时会按当前拼图布局生成 PNG 图片。

## 海报与文字

- 点击左侧“一键生成海报”可选择不同海报模板，当前已打开图片会直接应用到当前 tab。
- 海报中的图片支持圆形、椭圆、方形、长方形等多种嵌入形状。
- 海报和普通图片都支持右侧文字工具，可添加多个文字层并拖动调整位置。
- 文字内容、移动、删除、样式调整都会写入历史记录；空文本框未输入内容时会自动清理且不进入历史。
- 删除“应用海报样式”的历史记录时，会恢复成原始图片。

## 主题与界面

- 左侧“界面风格”可选择“跟随系统”“深色风格”“白色风格”。
- 主题选择会保存在本地，下次打开自动恢复。
- 右侧工具箱提供微调、文字、马赛克和历史记录入口。
- 历史记录面板在深色和浅色主题下都有独立高对比样式，便于查看和删除操作。

## 快速启动

### Electron 新界面（推荐）

macOS 在 Finder 中双击项目根目录下的：

```bash
Image Enhancer.app
```

这种方式不会打开终端窗口；如果启动失败，会显示系统弹窗，详细日志在 `~/Library/Logs/Image Enhancer.log`。

Windows 系统双击项目根目录下的：

```bat
start_image_enhancer_windows.cmd
```

首次启动会自动检查 Node.js/npm，并执行 `npm install` 安装 Electron 依赖，然后打开新版界面。

也可以双击备用启动脚本：

```bash
start_electron.command
```

首次启动会自动执行 `npm install` 安装 Electron 依赖，然后打开新版界面。`.command` 文件由 macOS Terminal 执行，因此会显示终端窗口，适合排查启动问题。

新版界面特点：

- 更接近 PS 的深色三栏式工作区
- 默认打开更大的桌面窗口
- 中心大画布预览，大图片会自动适应窗口完整显示
- 左侧快捷预设，包括“人像一键美化”和“婚纱照一键精修”
- 左侧风格化入口点击后展开多种风格样式，减少默认界面拥挤
- 左侧拼图入口支持把多张图片合并到一个拼图 tab 中排版
- 右侧手工微调参数
- 预览使用缩略图渲染，导出时按原图尺寸生成

### PyQt 旧界面

在 Finder 中双击项目根目录下的：

```bash
start_image_enhancer.command
```

首次启动会自动创建 `.venv` 虚拟环境，并安装 `requirements.txt` 中的依赖。

如果 macOS 提示没有执行权限，请在项目目录执行一次：

```bash
chmod +x start_image_enhancer.command
```

### 命令行启动

```bash
pip install -r requirements.txt
python src/image_enhancer.py
```

## 输出目录

默认导出到项目的 `output/` 目录，也可以在保存时选择其他位置。

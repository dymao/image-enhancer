# Image Enhancer

一个本地运行的桌面修图工具，用于快速处理图片亮度、对比度、饱和度、锐化、降噪、人像美化、婚纱照精修、黑白效果和旋转。

## 功能

- 打开 JPG、PNG、WEBP、BMP、TIFF 图片
- 调整亮度、对比度、饱和度
- 锐化图片细节
- 降噪处理
- 人像一键美化
- 婚纱照一键精修
- 风格化一键修图
- 美白、磨皮、瘦脸
- 柔光通透效果
- 黑白效果
- 左右旋转 90 度
- 预览缩放
- 导出 PNG、JPG、WEBP、BMP

## 人像美化

- 点击“人像一键美化”会自动设置推荐参数，包括亮度、对比度、饱和度、锐化、降噪、美白、磨皮和瘦脸。
- “美白”会先识别图片中的肤色区域，再局部提升肤色亮度，避免把背景、婚纱、天空一起变白。
- “磨皮”会基于肤色软蒙版做局部平滑，尽量保留背景、衣服和整体轮廓细节。
- “瘦脸”使用 OpenCV 本地人脸检测，对检测到的人脸区域做轻微横向收窄；如果检测不到人脸，会自动跳过，不影响其他效果。

## 婚纱照一键精修

- 点击“婚纱照一键精修”会自动应用偏柔和、通透、干净的参数组合。
- 默认会增强美白、磨皮和柔光，同时轻微提升亮度、对比度和饱和度。
- 美白和磨皮会优先作用在人像肤色区域，不会直接把整张婚纱照全部磨糊。
- “柔光”适合婚纱照、写真照和外景照，可以让高光更柔和、画面更明亮。

## 风格化一键修图

- 左侧默认只显示“风格化一键修图”入口，点击后才展开具体风格样式。
- “蓝天白云”：增强蓝色天空、提亮白云和高光，适合户外旅行照、外景照。
- “青色青春”：加入清爽青绿色调，同时保护人物肤色，适合校园、人像、写真。
- “暖阳胶片”：增加暖色高光和轻胶片感，适合日落、逆光、外景氛围照。
- “高级灰”：降低整体饱和度并增强层次，适合质感大片、商务照和简约风。
- “甜美樱花”：粉色高光、柔和肤色，适合少女写真和甜美人像。
- “赛博夜景”：蓝紫霓虹、高对比，适合城市夜拍和氛围街拍。
- “森林清新”：强化自然绿意和通透感，适合草地、树林、户外照。
- “复古港风”：暖红暗部和复古对比，适合街拍、人像和怀旧照片。
- “经典黑白”：黑白层次和强对比，适合纪实、肖像和情绪大片。

## 快速启动

### Electron 新界面（推荐）

在 Finder 中双击项目根目录下的：

```bash
Image Enhancer.app
```

这种方式不会打开终端窗口；如果启动失败，会显示系统弹窗，详细日志在 `~/Library/Logs/Image Enhancer.log`。

也可以双击备用启动脚本：

```bash
start_electron.command
```

首次启动会自动执行 `npm install` 安装 Electron 依赖，然后打开新版界面。`.command` 文件由 macOS Terminal 执行，因此会显示终端窗口，适合排查启动问题。

新版界面特点：

- 更接近 PS 的深色三栏式工作区
- 默认打开更大的桌面窗口
- 中心大画布预览，大图片会自动适应窗口完整显示
- 左侧快捷预设，包括“人像一键美化”和“婚纱照一键精修”
- 左侧风格化入口点击后展开多种风格样式，减少默认界面拥挤
- 右侧手工微调参数
- 预览使用缩略图渲染，导出时按原图尺寸生成

### PyQt 旧界面

在 Finder 中双击项目根目录下的：

```bash
start_image_enhancer.command
```

首次启动会自动创建 `.venv` 虚拟环境，并安装 `requirements.txt` 中的依赖。

如果 macOS 提示没有执行权限，请在项目目录执行一次：

```bash
chmod +x start_image_enhancer.command
```

### 命令行启动

```bash
pip install -r requirements.txt
python src/image_enhancer.py
```

## 输出目录

默认导出到项目的 `output/` 目录，也可以在保存时选择其他位置。
